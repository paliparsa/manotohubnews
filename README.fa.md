# Manotohubir News Worker — Multi-Provider AI Edition

نسخهٔ Cloudflare Worker برای جمع‌آوری خبرهای چندزبانه درباره ایران، اسرائیل، آمریکا، رضا پهلوی و تحولات نظامی/امنیتی مرتبط. فیدها هر ۵ دقیقه بررسی می‌شوند؛ مدل هوش مصنوعی خبرها را به فارسی بازنویسی می‌کند و خبرهای واجد شرایط بر اساس سیاست انتشار فعلی منتشر یا برای تأیید مدیر ذخیره می‌شوند.

## ارائه‌دهندگان هوش مصنوعی

پنل تلگرام سه ارائه‌دهندهٔ جدا دارد:
- **Google Gemini** — ارائه‌دهندهٔ اصلی پیش‌فرض.
- **Groq** — مسیر پشتیبان.
- **Cloudflare Workers AI** — مسیر پشتیبان دیگر با API Token و Account ID.

OpenRouter در مسیر اجرای فعلی استفاده نمی‌شود. کلیدها جداگانه با AES-GCM در Durable Object ذخیره می‌شوند. با انتخاب یک مدل در منوی «مدل هوش مصنوعی»، همان ارائه‌دهنده اصلی می‌شود؛ اگر اتصال، سهمیه یا خروجی JSON نامعتبر باشد، Worker سراغ ارائه‌دهنده‌های دیگری می‌رود که کلیدشان ثبت شده است. فقط مدل‌های متنی منتخب در فهرست‌ها نمایش داده می‌شوند؛ رایگان‌بودن و سقف سهمیه را خود سرویس تعیین می‌کند و ممکن است تغییر کند.

## راه‌اندازی اولیه

### 1) اتصال GitHub به Cloudflare
- Repository را در Cloudflare Dashboard → Workers & Pages → Connect to Git متصل کن.
- Root directory را ریشهٔ repository بگذار.
- Build command: `npm install && npm run typecheck`
- Deploy command: `npx wrangler deploy`
- بعد از تأیید استقرار، Push روی `main` به‌طور خودکار Deploy می‌شود.

### 2) سه Secret پایه در Cloudflare
در Worker `manotohubnews` → Settings → Variables and Secrets این موارد را ثبت کن:
- `TELEGRAM_BOT_TOKEN` — توکن ربات از `@BotFather`
- `ADMIN_TELEGRAM_ID` — شناسهٔ عددی ادمین
- `CONFIG_ENCRYPTION_KEY` — رشتهٔ تصادفی طولانی (حداقل ۳۲ کاراکتر؛ نمونه: `openssl rand -hex 32`)

کلیدهای AI را در GitHub یا `wrangler.toml` قرار نده. پس از Deploy از پنل خصوصی تلگرام ثبتشان کن. اگر `CONFIG_ENCRYPTION_KEY` را عوض کنی، اطلاعات قبلی قابل رمزگشایی نیست؛ قبل از تغییر، دسترسی‌های ثبت‌شده را از پنل حذف کن و پس از تغییر دوباره ثبت کن.

### 3) دسترسی ربات تلگرام
- ربات را به کانال `@Manotohubir` اضافه کن و مجوز ارسال پیام بده.
- Worker از webhook تلگرام استفاده می‌کند؛ webhook دیگری که به همین ربات وصل باشد ممکن است با این تنظیم جایگزین شود. برای این پروژه بهتر است ربات اختصاصی داشته باشی.

## مدیریت API و مدل‌ها از داخل بات
در گفت‌وگوی خصوصی ربات `/start` را بفرست. سپس:

- **🔐 مدیریت کلیدهای API** → دکمهٔ جدا برای Gemini، Groq و Cloudflare Workers AI.
- **🔎 Gemini / ⚡ Groq / ☁️ Cloudflare Workers AI** در منوی مدل‌ها → فهرست مدل‌های متنی منتخب همان سرویس.
- با زدن مدل، همان سرویس به‌عنوان اصلی انتخاب می‌شود و سرویس‌های دیگر در صورت داشتن کلید، پشتیبان می‌مانند.
- **🔌 آزمایش اتصال** → آزمایش مدل اصلی.
- `/status` → وضعیت ارائه‌دهنده و آخرین مدل استفاده‌شده.
- `/models` → فهرست مدل‌های ارائه‌دهندهٔ اصلی.
- `/test` → آزمایش اتصال ارائه‌دهندهٔ اصلی.
- `/myid` → نمایش شناسهٔ عددی تلگرام.

### قالب دسترسی Cloudflare
در دکمهٔ Cloudflare Workers AI، این دو مقدار را در یک پیام بفرست:

`ACCOUNT_ID | API_TOKEN`

توکن باید اجازهٔ استفاده از Workers AI و خواندن فهرست مدل‌ها را داشته باشد. شناسهٔ حساب ۳۲ رقم هگز است. پیام کلید پس از دریافت تا حد امکان حذف می‌شود و مقدار در Durable Object رمزگذاری می‌شود.

## زمان‌بندی و عیب‌یابی
- Cron: اجرای pipeline هر ۵ دقیقه.
- سقف پیش‌فرض هر اجرا: ۳۵ ورودی و ۴ پست.
- وضعیت Worker: آدرس Worker به‌همراه `/health`.
- گزارش اجرا و علت رد خبرها: دکمهٔ «📈 گزارش اجرا» در پنل ادمین یا Cloudflare Logs / Observability.

## محدودیت‌های مهم
- سهمیهٔ رایگان نامحدود نیست؛ محدودیت‌ها و دسترسی مدل‌ها بر اساس حساب و سیاست هر ارائه‌دهنده فرق می‌کند.
- فهرست مدل‌ها از API همان سرویس دریافت می‌شود، اما تنها مدل‌هایی که در کد برای پردازش متنی مناسب و واجد شرایط رایگان/سهمیهٔ رایگان تشخیص داده شده‌اند نمایش داده می‌شوند. اگر سرویس مدل‌ها را تغییر دهد، فهرست نیز ممکن است تغییر کند.
- جست‌وجوی موضوعی دستی در این نسخه از RSS/Atomهای تنظیم‌شده استفاده می‌کند؛ دیگر ابزار جست‌وجوی وب اختصاصی OpenRouter ندارد و URL ساختگی تولید نمی‌کند.
- خبر تک‌منبعی با برچسب «گزارش اولیه» نگه داشته می‌شود. چند منبع بودن به‌تنهایی استقلال آن‌ها را ثابت نمی‌کند؛ خبرهای جنگی، تلفات و ادعاهای نظامی ممکن است نیازمند بررسی انسانی باشند.
- اگر webhook ربات قبلاً برای سرویس دیگری استفاده می‌شده، تنظیم Worker می‌تواند آن را جایگزین کند.
